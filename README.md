# Kroy Chetra — Portfolio

## របៀបដំណើរការ (How to run)

1. ដំឡើង Node.js (v18+) ជាមុនសិន
2. បើក terminal នៅក្នុងថត project នេះ រួចវាយ:

```bash
npm install
npm run dev
```

3. បើក browser ទៅកាន់ link ដែលបង្ហាញ (ជាធម្មតា http://localhost:5173)

## ចំណុចដែលត្រូវកែបន្ថែម (TODO — search for "TODO" comments in the code)

- `src/components/Contact.jsx` — email, phone, ទីតាំងពិត

## Build for production

```bash
npm run build
```

Output នឹងចេញនៅក្នុងថត `dist/`.
